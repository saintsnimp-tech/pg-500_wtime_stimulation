# 澳洲学生签证等待时长数据

数据快照日期：2026-09-24（Asia/Shanghai）

本目录汇总澳大利亚学生签证（Student visa, subclass 500）等待/处理时长的公开数据。不同来源的统计对象和口径不可直接混用，因此按来源类型拆分。

## 文件分类

| 文件 | 类别 | 内容 |
|---|---|---|
| `01_official_current_streams_2026-09.csv` | 官方当前值 | 内政部签证处理时长指南的 7 个学生签证教育类别，50%/90% 分位 |
| `02_official_aggregate_quarterly_2022-2025.csv` | 官方历史汇总 | 2022-23 Q4 至 2024-25 Q4 学生签证总体中位处理时长与同期结案率 |
| `03_official_sector_quarterly_2024Q4-2025Q4.csv` | 官方历史分组 | 按境内/境外、教育类别、25/50/75 分位的五个季度序列 |
| `04_official_china_quarterly_2024Q4-2025Q4.csv` | 官方中国申请人 | 中国大陆申请人按境内/境外及 25/50/75 分位的五个季度序列 |

## 关键口径

- “50% processed in X”是近期已作决定申请的第 50 分位（中位数），不是剩余等待时间预测。
- “90% processed in X”是第 90 分位，不是承诺期限。
- 官网当前指南覆盖最近已决定申请，数值会随处理旧案、申请量、材料完整性及完整性审查而变化。
- 半年报中的处理时长只统计已获批的学生签证主申请（student PRIMARY visa applications granted）；拒签、撤回和仍在等待的申请不在这些分位中。
- 季度“flow rate”是某一批次在同季度或截至快照日已结案的比例，不等同于获签率。
- `0` 和 `<5` 按原表保留：`0`通常表示少于 1 个完整日；`<5`表示隐私/小样本抑制，不能当作精确的 0 或 4。
- 月份不统一换算为天。若平台直接提供天数则保留；否则同时保留原始字符串，避免用固定 30 天造成伪精确。
- 社区个案是自报数据，存在选择偏差、重复、日期错误和类别缺失；分析总体趋势时应默认排除。

## 建议使用顺序

1. 当前一般预期：先用 `01_official_current_streams_2026-09.csv`。
2. 中国申请人历史变化：用 `04_official_china_quarterly_2024Q4-2025Q4.csv`。
3. 教育类别与境内/境外差异：用 `03_official_sector_quarterly_2024Q4-2025Q4.csv`。
4. 长期压力与结案速度：用 `02_official_aggregate_quarterly_2022-2025.csv`。
5. 第三方和社区信号：只作为补充交叉验证，读取 `07`、`08` 及 `sources.csv` 的限制字段。

## 覆盖边界

“所有平台”不存在可稳定穷尽的公开集合。小红书、微信群、封闭论坛、需要登录的 ImmiAccount 个案状态以及不可公开抓取的帖子未纳入。目录覆盖了截至快照日可公开访问、可引用且与 subclass 500 等待时长直接相关的主要官方数据集、官方报告、FOI 数据、主流处理时长工具和一组可核验社区案例。
